独自ドメイン

お持ちのドメイン（例: app.example.com）で、サーバーの Web サイトや API を公開できます。HTTPS の証明書は自動で用意し、更新も自動です。1 台につき 3 本まで登録できます。

ドメインをお持ちでない場合は、無料の 4l.vc のサブドメイン が使えます。

つながるまでの流れ

  1. ドメインを追加する … お客様パネルでサーバーを開き、「独自ドメイン」のタブで、ドメインとつなぐポートを選んで追加します。
  2. 持ち主であることを示す … 画面に出る TXT レコードを、お使いの DNS に追加して「確認する」を押します。ほかの方のドメインを勝手に登録できないようにするための手順です。
  3. 向き先をこちらに向ける … CNAME を画面に出るホスト名に向けるか、A レコードを画面に出る IP アドレスにします。
  4. 1 分ほど待つ … こちらの設定に反映され、HTTPS の証明書が自動で用意されます。

Aドメイン画面に出る IP アドレス
  • パネルの画面にある「コピー」ボタンで、値をそのままコピーできます。
  • いちばん上の階層（example.com そのもの）には CNAME を付けられない DNS が多いので、その場合は A をお使いください。
  • Cloudflare をお使いの場合は、プロキシ（オレンジの雲）をオフ（DNS のみ）にしてください。オンのままだと証明書を用意できません。

プログラムの待ち受け

プログラムは、選んだポートを 0.0.0.0 で待ち受け、HTTP で応えてください。HTTPS への切り替えはこちらで行います。メインのポートは環境変数 SERVER_PORT に入っています（ポートの使い方）。

うまくいかないとき

  • 確認が通らない … DNS は行き渡るまで数分から数時間かかります。少し時間をおいて、もう一度お試しください。TXT の値は、前後に空白を入れずにそのまま入れてください。
  • 「設定まち」のまま … CNAME・A がこちらを向いているか確かめてください。Cloudflare のプロキシがオンだと、向いていないと判定されます。
  • 開くとエラーになる … サーバーが動いているか、プログラムが 0.0.0.0 で選んだポートを待ち受けているかを確かめてください。
  • 状態が「エラー」になった … 一度つながったあと、向き先が外れたときになります。DNS を直すと、自動で戻ります（「今すぐ確認」でもすぐ確かめられます）。
