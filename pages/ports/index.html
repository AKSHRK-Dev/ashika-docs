ポートの追加

サーバーには、初めからポートが 1 つ付いています。Web と Bot を 1 台で動かしたい、ゲームサーバーで別のポートも開けたい、というときは、ポートを追加で買えます。いくつでも追加できます。

料金

項目内容
月額1 個 10 円
買ったとき今の期限までの日割り（30 日で 10 円。1 円未満は切り上げ、最低 1 円）を残高から払います
そのあと期限を延長するたびに、プラン料金と一緒に払います（例: 月 50 円のプランに 2 個追加 → 延長は 70 円）
外したとき返金はありません。次の延長から料金に入らなくなります

追加のしかた

  1. お客様パネルでサーバーを開き、「ネットワーク」を開きます。
  2. 「ポートを追加する」で金額を確かめて、ボタンを押します。
  3. 番号は空いているものから自動で選ばれ、ポートの一覧に「追加」として出ます。

反映のため、サーバーを作り直します。動いていた場合は数秒〜数十秒止まって、自動で起動し直します。ファイルは消えません。

API からも追加できます（ポートを追加する）。

プログラムからの使い方

メインのポートは環境変数 SERVER_PORT に入っていますが、追加したポートは入りません。番号をそのままプログラムや設定ファイルに書いてください。待ち受けるアドレスは 0.0.0.0 にします。

import os

web_port = int(os.environ["SERVER_PORT"])  # メイン
api_port = 4057                            # 追加したポート（ネットワークの画面に出ている番号）

外すとき

「ネットワーク」のポートの一覧で、追加したポートの「外す」を押します。プランに付いているメインのポートは外せません。このポートにつないでいた サブドメイン・独自ドメインも一緒に消えます。
