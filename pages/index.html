ASHIKA Network ドキュメント

お客様パネルの画面の外から、サーバーを動かすための説明書です。プログラムから操作したいときは API を、たくさんのファイルを送りたいときは SFTP を使います。

API プログラムからサーバーを操作する 起動・停止・再起動、コマンドの送信、ファイルの読み書きを、HTTP で行えます。GitHub Actions からの自動デプロイなどに。 SFTP ソフトでファイルを送る FileZilla や WinSCP から、大きなファイルやフォルダをまとめて送れます。大きさの制限はディスクの上限だけです。

どちらも APIキーで入ります

API と SFTP は、お客様パネルの 「API」 で発行する APIキー（ashk_ で始まる文字列）を使います。ログインのパスワードは使えません。

  • キーは 1 つのアカウントで 10 個まで作れます。使う場所ごとに分けておくと、1 つを消しても他に影響しません。
  • キーの全体が見られるのは、発行したときの 1 回だけです。なくしたら、消して作り直してください。
  • キーを消すと、そのキーはすぐに使えなくなります。
