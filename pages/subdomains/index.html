4l.vc のサブドメイン

「myserver.4l.vc」のような、覚えやすい名前でサーバーにつなげます。ドメインを買わなくても使え、無料です。1 台につき 3 本まで作れます。

作り方

  1. お客様パネルでサーバーを開き、「サブドメイン」のタブを開きます。
  2. 好きな名前を入れ、つなぐポートを選びます。
  3. Web を公開するときだけ「自動 HTTPS を使う」にチェックを入れて、「サブドメインを作る」を押します。

すぐに使える状態になります。DNS が行き渡るまで数分かかることがあります。

使える名前

  • 英小文字・数字・ハイフン（-）で 3〜32 文字。ハイフンは最初と最後には使えません。
  • 早い者勝ちです。消すと、ほかの方が取れるようになります。
  • www・api・admin など、一部の名前は予約されていて使えません。
  • 他の方や団体になりすます名前、紛らわしい名前は、運営の判断で止めることがあります。

つなぎ方

使い方接続先
ふつう（ゲーム・Bot の Web 画面など）myserver.4l.vc:ポート番号
Minecraft（Java版）myserver.4l.vc（ポートは要りません）
Web（自動 HTTPS をオンにしたとき）https://myserver.4l.vc

Minecraft（Java版）は、サブドメインを作ると SRV レコードが自動で作られるので、ポートを付けずにつながります。統合版（Bedrock）は SRV に対応していないので、ポート番号を付けてください。

自動 HTTPS

オンにすると、https://名前.4l.vc で Web サイトや API を公開できます。証明書は最初のアクセスのときに自動で取り、期限の前に自動で更新します。

  • プログラムは、選んだポートを 0.0.0.0 で待ち受け、HTTP で応えてください（HTTPS への切り替えはこちらで行います）。
  • ゲームサーバーや Bot だけなら、オフのままで構いません。オン・オフは「サブドメイン」のタブからいつでも切り替えられます。

DNS レコードを足す

自分のサブドメインと、その下の名前に DNS レコードを足せます。メールの送信元の確認（SPF）や、証明書の取得（_acme-challenge）、別のサービスへの向き先などに使えます。

種類付けられる名前値の例
TXTサブドメインそのもの、またはその下v=spf1 -all
CNAMEその下の名前だけ（例: www.myserver.4l.vc）example.github.io
Aその下の名前だけ203.0.113.10
AAAAその下の名前だけ2001:db8::10

サブドメインそのもの（myserver.4l.vc）の A レコードは、サーバーにつなぐために使っているので変えられません。1 つのサブドメインにつき 20 件まで足せます。

「サブドメイン」のタブで、サブドメインの「DNS レコード」を押すと、足したり消したりできます。API からも操作できます（サブドメイン）。

うまくいかないとき

  • つながらない … サーバーが動いているか、プログラムが 0.0.0.0 で、選んだポートを待ち受けているかを確かめてください。
  • 名前が見つからないと言われる … 作った直後は、DNS が行き渡るまで数分かかることがあります。
  • https:// で開けない … 自動 HTTPS がオンになっているか、プログラムが HTTP で応えているかを確かめてください。オンにした直後は 1 分ほどかかります。
